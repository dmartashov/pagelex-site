# pagelex-site

The website of PageLex at https://pagelex.app, served by GitHub Pages from `main`.

- Static HTML and CSS only: no analytics, no cookies, no outside scripts or fonts (PageLex DECISIONS §2.14).
- `index.html` (English), `es/index.html`, `de/index.html`: the home page, generated by `tools/build_home.py`.
  Edit the texts in that script, then run `python3 tools/build_home.py .` from the repository root. Don't edit the three HTML files by hand.
- `support/index.html`: the App Store Support URL.
- `assets/`: the stylesheet and the icon.
- `CNAME`: the custom domain. Don't delete it.

The book page in the demo of the English and Ukrainian pages is public domain: Lewis Carroll, "Alice's Adventures in Wonderland" (1865). The Spanish and German drafts still use Arthur Conan Doyle, "The Red-Headed League" (1891).
